# FakeNewz — Fake News Detection Web App

FakeNewz is a beginner machine learning project that detects whether a news headline is fake or real using natural language processing and a simple web interface.

## Features
- Detects fake vs real news headlines
- Uses TF-IDF vectorization
- Logistic Regression classifier
- Flask-based web interface
- Keyword-based spam detection for suspicious phrases

## Technologies Used
- Python
- Flask
- pandas
- scikit-learn
- TF-IDF Vectorizer
- Logistic Regression

## Project Workflow
1. Preprocess input text
2. Convert text into numerical vectors using TF-IDF
3. Train machine learning model
4. Predict whether news is fake or real
5. Display result on web interface
